📖 Ürün Paneli Nasıl Çalışır?

Bu panel doğrudan GitHub deponuz ile haberleşir. Eklediğiniz veya güncellediğiniz tüm ürünler anında _data/urunler/ klasörüne kaydedilir.

🚀 Otomatik Vercel Güncellemesi

Bir ürünü kaydedip yayınladığınızda Vercel 15-20 saniye içinde sitenizi otomatik olarak günceller ve yeni ürün tüm ziyaretçiler için yayına girer.

🔑 GitHub API Anahtarı (Token) Nedir?

Tarayıcınızın GitHub'a ürün kaydedebilmesi için ücretsiz bir GitHub Token'ına ihtiyacı vardır. Sağ üstteki "⚙️ API Ayarları" butonuna tıklayarak tokeninizi bir kere girmeniz yeterlidir.

⚙️ GitHub API & Token Ayarı

Panelin doğrudan sitenize ürün ekleyebilmesi için GitHub Personal Access Token gereklidir.

Nasıl Token Alınır? (1 Dakika):
1. Buraya tıklayarak GitHub token sayfasını açın.
2. "repo" kutucuğunu işaretleyin ve en alttaki yeşil "Generate token" butonuna basın.
3. Size verilen ghp_... ile başlayan kodu kopyalayıp yukarıdaki kutuya yapıştırın.
